UPDLOCK, READPAST, and ROWLOCK are query hints used in the dequeue. UPDLOCK ensures that each row intending to be updated has an update lock. Instead of shared locks, this ensures only one process/worker can update this row. READPAST allows for locked rows to be skipped so that other workers can continue to do work on rows without locks. Finally, ROWLOCK tells SQL Server to lock at the row level rather than at the page level. Without it, neighboring rows may be locked. Without these three, our dequeue would face race conditions.
